# CompraAmigoFrontend

## Integración de compra

Esta etapa adapta la base compartida y las pantallas de compra de Sprint 1 a la estructura del repositorio.
Cada pantalla tiene su carpeta con TypeScript, HTML y CSS.
Incluye registro con Angular Material, catálogo, perfil, carrito, checkout, historial e inventario.
Ejecuta `npm.cmd ci`, `npm.cmd run build` y `npm.cmd start`.
El proxy local reenvía `/api` al backend de Sprint 1 en el puerto 8080.
